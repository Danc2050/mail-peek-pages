Privacy policy

Mail Peek · last updated November 8, 2026

Mail Peek is a personal tool used by its author only. It runs entirely on the author's own computer.

What it accesses

With the user's permission (the Gmail gmail.modify scope), Mail Peek reads messages and labels in the signed-in Gmail account, changes labels (read/unread, archive, trash) and sends replies the user writes. It cannot permanently delete mail.

Where the data goes

Messages are cached in a local database on that same computer so they can be searched and shown quickly. The sign-in token is stored there too, readable only by the user's account. Mail Peek talks only to Google's own APIs. It has no server of its own, no analytics and no advertising, and it never sells, shares or transfers anyone's data to a third party.

Google API data

Mail Peek's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the app's folder deletes the local cache and token.

Questions: open an issue at github.com/Danc2050/mail-peek-pages.
